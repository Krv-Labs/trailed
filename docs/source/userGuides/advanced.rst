.. _advanced:

========
Advanced
========

Use optional plugin adapters for end-to-end ML integration.

- ``EctTransformer`` for sklearn pipelines (point clouds).
- ``DataFrameEctTransformer`` for pandas/polars pipelines (supports point clouds and graphs via ``edge_index``).

For PyTorch workflows, use the upstream `aidos-lab/dect <https://github.com/aidos-lab/DECT>`_ package.
